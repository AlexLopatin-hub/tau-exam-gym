# Вопросы по ТАУ

Сервис на Go, templ и htmx. Пока рабочий банк не предоставлен, используются 33 демонстрационных вопроса.

## Запуск

Нужен Go 1.26+:

```sh
go run .
```

Откройте http://localhost:8080. Билет доступен на сервере 24 часа с момента создания или до перезапуска. Общий лимит — 2 000 билетов, включая завершённые. Для аудитории в 200 человек это в среднем 10 билетов на человека за 24 часа. Если все места заняты, новый билет можно создать после истечения срока одной из попыток. Лимит отправки ответов на весь билет — 256 КиБ в закодированной форме.

При открытии результата браузер сохраняет копию билета в локальном хранилище. На вкладке «Экзамен» в разделе «Пройденные экзамены» можно открыть исходные вопросы, правильные и свои ответы даже после изменения банка или перезапуска сервера. Очистка данных сайта удаляет локальную историю.

Тесты запускаются командой `go test ./...`.

## Конспекты лекций

Добавляйте Markdown-файлы в `internal/exam/lectures/` с именами `ММ.ДД.md`, например `10.17.md`. В меню лекции идут от старых к новым, даты отображаются словами, например `17 октября`. Адрес этой лекции — `/lectures/10-17`. При открытии вкладки выбрана последняя лекция. Для формул используйте `$...$` внутри строки и `$$...$$` для отдельного блока.

После изменения конспектов выполните `go generate ./internal/exam` и добавьте обновлённый `internal/exam/lecture_pages.json` в коммит. `make build` запускает генерацию автоматически. Сервер читает встроенный готовый HTML при запуске, поэтому `go run .` использует последнюю сгенерированную версию лекций. GitHub Actions проверяет, что HTML соответствует Markdown.

## Проверка шаблонов перед коммитом

После клонирования один раз выполните `git config --local core.hooksPath .githooks`. Перед каждым коммитом Git проверит подготовленные файлы командой `go tool templ generate -check`. Если шаблон и Go-файл расходятся, коммит остановится. Выполните `go tool templ generate`, добавьте обновлённые файлы в индекс и повторите коммит.

GitHub Actions повторяет проверку при push и в pull request. Чтобы проверка блокировала слияние, в правилах ветки `develop` задайте обязательный pull request и обязательную проверку `Check generated templates`.

## Свой банк

Задайте `QUESTION_BANK` как путь к JSON-массиву объектов с полями `id`, `text`, `answer`, `topic`, `difficulty`. Для экзамена нужны три темы по десять вопросов; идентификаторы должны быть уникальными, все поля заполнены. Допустимые значения сложности: `лёгкий`, `средний`, `сложный`. Сложность — характеристика без квот.

```powershell
$env:QUESTION_BANK = "D:\\data\\questions.json"
go run .
```

Шаблон загружает htmx 2.0.11 с jsDelivr. Браузер проверяет SHA-384 файла перед выполнением.
