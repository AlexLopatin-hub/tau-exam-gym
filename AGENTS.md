# Сервис подготовки к экзамену

Заголовок страницы и вкладки браузера — «Вопросы по ТАУ». Пользователь открывает тренировочный билет и может свериться с ответом на отдельный вопрос или завершить экзамен и открыть весь ключ. Интерфейс на русском языке. Сервер написан на Go, HTML формируется шаблонами templ, htmx обновляет содержимое при переходах.

## Банк вопросов

- Рабочий банк рассчитан примерно на 300 вопросов. Это ориентир по объёму, а не ограничение на размер файла.
- У каждого вопроса есть уникальный идентификатор, формулировка, правильный ответ и уровень сложности (лёгкий, средний или сложный).
- По умолчанию сервис использует встроенный банк из 60 вопросов из `Voprosy.docx`.

## Пользовательские сценарии и критерии приёмки

1. Вкладка «Экзамен» предлагает начать экзамен. Открытие вкладки само по себе не создаёт попытку.
2. Для каждой новой попытки сервер случайно выбирает 20 вопросов из общего банка без повторений: 7 лёгких, 7 средних и 6 сложных. Билеты разных попыток могут пересекаться.
3. В билете сначала идут лёгкие вопросы, затем средние и сложные. Обновление страницы сохраняет состав и порядок вопросов.
4. Карточки обеих вкладок загружаются с текстом ответа. В активном билете и в каталоге «Показать ответ» и «Скрыть ответ» переключают видимость в браузере без сетевых запросов. Между переключателем и открытым ответом есть отступ. В активном билете у каждого вопроса есть поле для своего ответа. До завершения экзамена текст можно редактировать. Черновики хранятся в `sessionStorage` и восстанавливаются после обновления билета в той же вкладке. В каталоге полей ввода нет.
5. Кнопка «Завершить экзамен» закреплена снизу у правого края колонки с вопросами. Её фон занимает только место вокруг кнопки, в том числе на телефоне. В завершённом билете все правильные ответы постоянно видны на светло-абрикосовом фоне. Карточки результата не содержат переключателя ответа. Обновление страницы и повторное завершение сохраняют полный ключ. Рядом с каждым правильным ответом показан ответ пользователя или отметка о пропуске. Пользователь сверяет ответы самостоятельно. Баллы не рассчитываются.
6. Вкладки «Экзамен» и «Все вопросы» визуально обозначают текущий раздел и используют общий компонент карточки вопроса. Под заголовком каталог делится на три вкладки по сложности: «Лёгкие», «Средние», «Сложные». Выбранная вкладка сохраняется в URL. Внутри вкладки вопросы идут в порядке банка без разбиения на страницы. Текущая вкладка выделена. На карточке указаны формулировка и сложность. Ответы изначально свёрнуты. Пользователь может открывать и скрывать их независимо от экзамена.
7. Если в банке недостаточно вопросов любого из уровней сложности, запуск возвращает понятное сообщение. Частичная попытка не создаётся. При открытии неизвестной попытки или неизвестного раздела каталога пользователь видит страницу ошибки.

## Границы реализации

Минимизируйте собственный JavaScript. Используйте Go и templ для формирования HTML, htmx для переходов, возможности HTML и CSS для взаимодействия и оформления. Собственный JavaScript оставляйте для задач, требующих браузерных API.

История завершённых экзаменов хранится в localStorage этого браузера.

Авторизация, профили и аналитика отсутствуют. Пользовательские ответы хранятся вместе с завершённой попыткой. Для первой версии допустимо хранить попытки в памяти процесса до его перезапуска. HTTP-маршруты, редиректы и форматы ответов описаны в `api/openapi.yaml`. Сервер отдаёт HTML для браузера и HTML-фрагменты для htmx.
